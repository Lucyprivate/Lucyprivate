## How I work

- Start with the original design or a traceable source, and preserve its identity.
- Make assumptions and failure cases visible alongside the result.
- Distinguish my domain decisions and coursework contributions from Codex's implementation and automated checks.

My original Plume coursework role was **Grasshopper component-network assembly**. The new software implementation, automated verification and rendering in these portfolio extensions were performed by Codex with my direction and resources. These are learning and research prototypes, not construction or compliance certifications.
