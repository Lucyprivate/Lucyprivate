# AEC portfolio

These five studies connect architecture, engineering and construction (AEC).
They use source evidence to examine designs, models, and urban data.

| Study | Project question | View |
|---|---|---|
| Hong Kong Urban Site Study | How can model changes retain source evidence? | [Project](https://github.com/Lucyprivate/hong-kong-urban-site-study) |
| Void-Aware IFC Review | Can geometry and quantity units support a declared slab area? | [Case study](ifc-review.md) |
| The Plume Passage | Can a review preserve the original shared assembly? | [Case study](plume.md) · [24-second film](media/plume.mp4) |
| Palace of Fine Arts | Can reference sources guide an architectural reconstruction? | [Case study](palace.md) · [36-second film](media/palace.mp4) |
| Harbour Atlas | Can city views retain official data sources and limits? | [Case study](harbour.md) · [60-second film](media/harbour.mp4) |

The pages record local project development and inspection.
The latest urban snapshot dates from **14 October 2026**.
The urban study covers **100 km²** in **100 one-kilometre blocks**.
Its model retains black building attributes, gray terrain, and blue water.
The current profile image shows an urban river district, rather than the full site.
