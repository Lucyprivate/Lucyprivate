# AI-native Quant Trading System

**AI-native quant trading system builder | Python · Algorithmic Trading · AI-assisted Engineering**

I am building an AI-assisted quantitative trading system that turns a real manual-trading pain point into a modular Python engineering project. The system started from IBKR manual limit-order trading and evolved into a paper-trading platform with strategy modules, backtesting, ML signal gating, async execution, Telegram monitoring, risk controls, and ongoing SQLite/SQLAlchemy data-layer migration.
