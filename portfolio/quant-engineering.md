# Quant Trading System

**Python · Algorithmic trading · Software engineering**

## Goal

The project turns manual limit-order trading into a modular Python system.
It started with manual trading on Interactive Brokers (IBKR).
The current system supports paper trading, strategy modules, backtesting, and risk controls.
It also includes machine learning (ML) signal filters, asynchronous execution, and Telegram monitoring.
Current work moves CSV/JSON logs to SQLite and SQLAlchemy.

<a id="featured-project"></a>

## Public case study

[Quant Trading System](https://github.com/Lucyprivate/quant-trading-system)

The public repository documents architecture, Git history, refactoring, and development methods.
It excludes account data, API keys, and proprietary strategy parameters.
The public demo does not represent the private trading system.
